# PRDs

Este diretório organiza os documentos de requisitos de produto do projeto.

- O `PRD-00-indice.md` reúne a visão das telas, rotas, fluxos e decisões relevantes.
- Os demais arquivos `PRD-XX-<nome-da-tela>.md` descrevem os requisitos de uma tela específica.

Antes de propor ou implementar uma mudança, consulte o índice e os PRDs relacionados à tela ou fluxo afetado.
